# 断剑归途

《断剑归途》是一款俯视像素 RPG。玩家在村镇与野外探索，招募同行伙伴，经营安置乡亲的营地，并在可暂停的即时战斗中指挥小队。

白桦村遭袭后，主角护送村民撤离，负伤后在灰岩营地醒来。搭档下落不明，返乡的官道被黑鸦寨封锁。为了回去寻找线索，你得先让营地站稳脚跟。

## 玩法

- **探索与伙伴。** 和镇民交谈、调查沉眠古窟，在装备、物资和情报之间做取舍。阿禾可以跟你出战，也可以留营照看粮田。
- **经营与出征。** 士兵既能驻守和出战，也能在粮田或工坊工作。抽调人手会影响当日生产，战后的伤员、损失和补给会影响下一次出征。
- **小队即时战斗。** 在实际地图上部署剑士、弓兵、骑兵和法师。开战后可以暂停观察，再下达移动、驻守和集火指令。狭口和高地会改变你布阵与接敌的方式。
- **守营与返乡。** 第一次守住营地后，可以补给出征，主动攻打黑鸦寨，也可以留营准备第二次防守。打通归路后，回白桦村调查和重建。

## 下载试玩

[DEMO v0.1.0 发布页](https://github.com/Austwed/RPGDemo/releases/tag/v0.1.0)

- [Windows x64 ZIP](https://github.com/Austwed/RPGDemo/releases/download/v0.1.0/RPGDemo-Windows-x64-0e2e657.zip) · 完整解压后运行 `DEMO.exe`。用 WASD 或方向键移动，靠近目标并面向它后按 E 交互。
- [Android ARM64 APK](https://github.com/Austwed/RPGDemo/releases/download/v0.1.0/RPGDemo-Android-arm64-0e2e657.apk) · 支持 Android 8.0 及以上。安装后横屏游玩，使用摇杆和触控按钮。APK 使用调试签名。

首次游玩请在主菜单选「开始新游戏」，从白桦村序章开始。

## Unity 工程

工程使用 Unity `6000.6.4f1`，资源通过 Git LFS 管理。游戏从 [Demo_Launcher](Assets/Scenes/Demo_Launcher.unity) 启动，并加载正式游戏场景。
