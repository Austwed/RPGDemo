# 字段字典与配表说明

## 工作簿页签

[系统数值配置表](../基地征服-系统数值配置表.xlsx)维护当前 Demo 的数值。导入器用 Excel 表名、表头和稳定 ID 定位字段。单位模板、职业、装备和关卡引用等配置区把记录 ID 放在名称前。总表的运行顺序列用于保留按位置读取的数组或配置列表顺序，按名称或数值排序时随行移动。

| 系统 | 页签 |
| --- | --- |
| 职业与单位 | 职业、单位模板、人物预设 |
| 战斗与关卡 | 战斗规则、地形与视野、军需效果、关卡编制与配装 |
| 装备与成长 | 装备与商店、装备品质、队长成长与训练 |
| 经营与兵源 | 营地与设施、兵源、商品与配方 |
| 技能与特性 | 技能、特性 |
| 开局与进程 | 开局资源、奖励与遗迹、阶段参数 |

目录可跳转到「字段定义」。按页签或配置区筛选可查字段键、值类型、单位、引用和填写规则。战斗规则、配方等共用「数值」列的配置区按参数逐项列出类型。

[试玩调参表](../基地征服-试玩调参表.xlsx)有四页，列名简短，射程、价值阶段、产量及军需等填写口径可从表头批注查看。隐藏列随同行保存关联和导出原值，供 Unity 识别实际改动。

| 页签 | 可调字段 |
| --- | --- |
| 职业与单位 | 普通兵生命、攻击、防御，职业普攻距离 |
| 装备与商店 | 基础装备与新手装备属性及价值阶段，按槽位和阶段共用的基础价值 |
| 营地产出 | 粮田和工坊岗位上限、单位产量，每份一级军需耗用原料 |
| 关卡与军需 | 军需档位的攻、防、生命比例增幅，指定槽位的档位，按职业或全军发放的档位与人数 |

## 四职业与敌方军需

在总表「单位模板」的 Excel 表内追加一行，填写唯一记录 ID、名称、现有职业 ID、身份、基础生命、攻击、防御和视野。每个职业与身份必须有且仅有一个默认模板，新增变体使用 FALSE。关卡变体再在「关卡编制与配装」关联所用模板和实际部署槽位。黑鸦寨 `ranged-3` 使用 `blackcrow_watch_mage`。第二波对应原槽位的变体须保留同职业。

指定槽位每槽一人。职业或全军配装按配置行发放，先处理指定槽位，余下按游戏的军需分配规则处理。「职业普攻距离（细格）」作用于该职业的各身份，普通兵数值单独维护。

装备基准购入价使用槽位、价值阶段、一般品质的价值倍率和购买倍率，进位取整，最少 1 币。表内浅灰结果列为基准报价，游戏内实际交易另计特性。属性和价值倍率分开计算。

`cfg_training` 的目标等级、兵书种类和数量继续用于升级。旧表的 `days` 列为兼容导入保留，运行时立即升级。副本配置的旧键 `reward_cost` 对应确认开战或扫荡时消耗的体力，现行配表为 20。

## 导入与回写

1. 保存工作簿。在 Unity 打开「SLG → 其他工具 → 导入 → 导入策划表」，选择工作簿，核对逐字段差异，确认导入。
2. 总表完整生成配置。如果磁盘总表的有效值比最近完整导入的总表有变化，先导入总表再加载试玩。列宽、排序和冻结区域等格式变化不触发此检查。
3. 试玩表只应用当前值与导出原值之间的差异，以最近完整导入版本为底。后一次试玩替换前一次。若同一格的导出原值、当前总表值和试玩拟写值各不相同，导入提示三值并停止。重复 ID、非法引用或错误类型也中止写入。
4. 保留一次试玩的数值时，点「写回总表」。核对保存后的总表，完整导入后可用「重新生成试玩调参表」取得新的导出原值。恢复试玩前的数值可以直接重新导入原总表。
5. 导入更新随包配置、男女营地和首防阶段档，以及编辑器专用的调参备战档。已创建的游戏存档使用自身的配置。验收新数值时，选择刚生成的阶段档或新建游戏。

## 现场演示

1. 导入总表或未改动的试玩表，从导入窗口点「载入调参备战档」。选中法师，普攻无挡直线第 7 细格的固定目标。射程为 6 时，界面显示超出攻击距离。
2. 在试玩表把法师「职业普攻距离（细格）」从 6 改为 8，保存并导入。从同一窗口载入本次重新生成的备战档，再选该法师普攻。目标出现法术伤害并减少生命。
3. 如需展示营地产出，以新的试玩文件只改粮田每人日产量。预览同时列出法师距离恢复与粮田变化。载入新阶段档，确认粮田新值。
