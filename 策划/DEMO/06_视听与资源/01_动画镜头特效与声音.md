# 动画镜头特效与声音

## 动作

图集四行使用正、左、右、背顺序。静帧、待机、行走与攻击各读取其真实图集和规格，不把没有动作图的 NPC 强制拼动画。普通步行角色只要有横向位移优先面向横向，纯纵向再前后；停下保留最后朝向。单方向输入撞墙仍立即转向输入方向并保持待机。攻击与骑乘四向按各自规则。

攻击动作与实时模型出手、前摇、发射和命中区分；动画不重复触发伤害。近战挥击、飞行弹道、伤害浮字、生命条和倒地分别反馈对应状态。骑兵撞开与前摇打断按战斗事件表现，不额外加击飞伤害。

选角时，两位主角同用正向参考站姿并保持静止。男主向右的八帧按两个完整步幅循环，沿用统一脚底基准。

男女主的长椅动作使用各自独立的正面站姿、屈膝和坐姿图。入座正播，起身逆播，落座后定在最后一帧。

春婶、老周、通用村民和小芸在探索中按实际位移播放四向步态，每行走约 1.4 地图格完成一次循环，最短散步也能看到交替落脚，停步回到原朝向站姿。小芸的四向站姿与行走使用统一脚线和人物高度，站姿保留绘制时的柔边透明度。人物对白与各管理界面按外观共用半身像，雷恩沿用原画裁片。角色背包的全身展示使用四向站姿图集。

## 战术叠层

部署区只在部署阶段显色，正式开战移除残留色块。部署与即时战斗中，单位脚下显示其实际碰撞轮廓，我方蓝色、敌方红色。剑、弓、骑、法的占地均为一个细格。骑兵按脚下单格显示阵营色，面向与冲撞沿移动方向更新。倒地单位绘制在存活单位下方。古窟受控镇民从备战到交战沿用村民形象，出手播放村民攻击动作。选中、射程、路径、集火、驻守和迷雾各有独立含义。查看格白框，驻守成功黄框。普通士兵卡用职业文字和剩余数，不使用三个兵种图标。未知敌人不因情报面板泄露位置。

## 镜头

探索跟随主角，允许现有缩放／平移；部署复用真实战场相机，在区外空地起手拖动平移，布兵手势不同时拖相机。战斗可选头像、点格和滑选；菜单及模态框阻止镜头和地图命令。地图相机范围与 UI 安全游戏框保持一致，避免边框悬空。

切换地图时，原镜头停在出发位置。需要加载场景时，先盖住画面，等目的地的地形、人物、镜头与界面就位后再淡入。

序章刺伤、苏醒、救人和返乡以当前对白及场景切换承接，不要求小说中每个动作都有独立过场动画。连续剧情中的环境描写是叙事底稿，新增镜头需明确事件入口。

## 场景配乐与交互音效

| 声音 | 触发 |
| --- | --- |
| 主菜单与地面探索 | 主菜单的村景、白桦村、灰岩营地、灰岩镇和野外共用《Medieval: Exploration》。从地面回标题时续播同一首曲子。从遗迹或战斗回标题时，先收掉遗迹、交战和战果音乐，再恢复探索曲。切回游戏窗口后按当前音量恢复。部署期间沿用所在地的配乐。 |
| 林间环境 | 标题村景和白桦村序章使用林间底声，民兵演练期间调低音量。 |
| 地下回廊 | 踏进回廊时淡入《Fantasy: Rising Moon》，与迦兰对峙、交战时沿用。回到地面时恢复探索曲。 |
| 战斗与战果 | 序章追兵现身时切入战斗曲，剑伤后的旁白与选项使用全黑背景，随后在灰岩营地醒来。阿铸切磋、守营和攻寨等交战使用《Medieval: Battle》。正式战斗出结果时，背景音乐降低音量，带出一段胜利或败退乐句。民兵演练、序章断后、首次切磋直接接人物对白。 |
| 草地、石板、泥沙脚步 | 主角每移动约 1.65 地图格播放一次，以脚下实际铺面选音。石板路及其铺进邻格的边沿、转角都用石面脚步，踏出铺面才换草地轻足音。台阶和地下回廊用石面脚步，泥沙用泥沙声。同种地表轮换短音。 |
| 对白翻页 | 完成本页后翻到下一页时响一声。 |
| 派工确认 | 白桦村派工和营地调岗成功提交时响一声。 |
| 商铺与奖励 | 交易成功响钱币声，募兵成功响轻铠声，重铸完成响金属回音，首次展示已发放的奖励响收物声。 |
| 战场动作 | 出手时响挥剑或弓弦，实际命中时响碰撞，人物倒地时从四段真人短呼中选一段，相邻两次使用不同录音。骑兵进入新格时响马蹄，木桩受击响木头声。声音随距离衰减，迷雾中的敌人不通过音效透露位置。 |

音乐均由 RandomMind 创作，林间环境录音来自 TinyWorlds。三首长曲按场景淡入淡出，使用流式读取。战果短乐句随音乐音量调整，环境、脚步和操作声随音效音量调整。素材作者、原件和 CC0 授权见[音频来源](../../../RPGDemo/Assets/Resources/Audio/VillageOpening/Credits.txt)。

主菜单、探索、部署和战斗的「选项」通往声音设置。音乐、音效均可调到 0–100%，拖动即时生效，设置跨局保存。音效一项包含环境声与操作、战斗短音。
