# 地图与内容编辑接入

## 正式底稿

七图为白桦村、灰岩营地、灰岩镇、遗迹入口、地下回廊、迎敌战场、黑鸦寨，返乡复用白桦村。结构化底稿和对象表见[地图数据](../02_流程与关卡/目录.md#地图数据与坐标)。地图角色、稳定对象 ID、剧情功能和外观键分别保留，改外观不自动改变功能。

地图地格记录地形、表面、高度、坡道与部署区；对象记录连续中心、占地、阻挡、地基、外观与功能。格索引按 y×width+x，逻辑坐标与渲染高差分开。楼梯与跨层通行从同一坡向判断，碰撞和遮挡不能分别猜高低。

## 编辑与测试

在根目录「独立编辑器」启动设计台，选择从正式地图新建设计。修改地形、设施、人物、出生点和部署区；另存创作 JSON，再检查设计与接入提示。必需剧情对象不能删掉或换成无身份同名人偶。

导出检查必需对象、出生落点、关键点可达、序章撤离范围、战场部署区、骑兵空间及双方通路。成功导出到 StreamingAssets/StoryScene 的测试包；编辑模式通过「SLG→地图编辑→自定义地图测试新档」进入。正式 Play 和发行入口保持正式地图。

测试档按地图包编号独立保存，不污染普通档。游玩不回写设计源，浏览器恢复草稿也不等于磁盘保存。包无效时给地图、对象和坐标原因，不能静默改用另一份地形当测试成功。

### 作品集网页与来稿演示

[场景地图编辑器](../../../独立编辑器/作品集网页版/index.html)随单个网页提供七图预设与布景素材。访客可拖动对象、输入坐标、增删自己的布景、修改地表并撤销。导出时检查七图与剧情通路，生成一份含创作数据与游戏布局的 JSON；这份文件可直接在网页重开。

演示者在 Unity 的「SLG → 地图编辑 → 从 JSON 打开地图测试」选择来稿。入口校验文件后从白桦村开局，使用来稿的地图与正式剧情。每份布局按地图包编号保存测试进度，选角取名后建立自动档。网页内仅编辑场景，运行效果在 Unity 中展示。

## 内容接入

文本由 story-text.json 和对白入口共同组成，动态变量只在所属业务计算；修改既有文本键不改变事务。新支线先补场景骨架、前置、一次性标志和结束汇合，再加内容入口。任务文字和箭头读取同一目标定义。

固定 UI 在 Base_Stage2 的布局源直接编辑；运行时重复元素从对应模板克隆。导入人物图、建筑图和材质时保留 .meta，资源键与逻辑 ID 不随文件显示名称任意更换。

标题页在「UI 布局源 / VillageTitle」编辑。村民的路线端点、行走和停留时长，兔子的洞口与草地位置均随标题预制体保存。游戏内白桦村的岗位、碰撞和事件沿用正式地图。

## 版本和发布

通用设计格式、剧情测试包、存档和数值包分别校验版本。发行安卓脚本默认排除自定义测试包与开发档资源。若决定把自定义地图作为正式版本，需明确改为正式基线并验证完整流程，不能只把测试包留在 StreamingAssets 视为已发布。
