# DEMO 重点策划案

Windows／Android · 单人横屏 · 2026-11-16

## 1. 游戏概述

《DEMO》是一款俯视像素 RPG。玩家以主角身份探索村镇和野外，选择同行伙伴，同时经营难民营地，指挥至多三名队长及其小队进行可暂停的即时战斗。

主角曾是王都禁卫，与搭档离开王都后在白桦村定居。古裔袭击村庄，搭档留下断后，主角护送乡亲撤离，却被追兵手中的王室秘银剑刺伤。醒来时，乡亲在灰岩营地暂住，搭档下落不明，返乡的官道也被黑鸦寨封锁。玩家要让营地站稳脚跟，再回白桦村寻找线索。

## 2. 玩法

### 2.1 RPG 剧情扮演线

新局选择主角外观、填写姓名，另一位可选角色成为搭档。玩家在场景里步行，通过与人物交谈、调查物件和进出不同地点推进故事。任务提示指向当前目标，镇上的交易、装备重铸和野外可选挑战则留给玩家自行探索。

主角要先安顿乡亲，再寻找失踪的搭档，并追查王室秘银剑为何落到古裔手里。玩家从白桦村撤离，到灰岩镇求助，再经古窟救援和营地遇袭，最终回到断桥找到新的线索。

对话和行动会改变同行者与接下来的经历。阿禾加入后可以随队担任弓手，也可以留营负责粮田，发挥她的种植专长。玩家选择先见领主还是先去古窟，也会听到不同的交差对白。

### 2.2 战斗经营循环

**安排生产与人员 → 整备、部署与指挥 → 承担战损、获取收益 → 恢复和补员。**

1. **安排生产与人员。** 把普通兵安排到粮田或工坊，补充口粮和军需。营帐能预览日结收支，休息与世界行军都会推进日期。普通兵要在岗位和出征队之间调配，也占用日常口粮。队长可以随行、训练或留营负责设施，日口粮为零。
2. **整备、部署与指挥。** 看已知敌情和战场目标，按队长分配剑士、弓兵和骑兵，在实际地图上落位。开战后可暂停观察，再下达移动、集火或驻守命令，也可以交给小队按进攻、防守策略自主行动。
3. **承担战损、获取收益。** 正式战斗留下实际伤势、阵亡和军需消耗。战利品补充库存，符合条件的俘虏可以接纳。
4. **恢复和补员。** 伤员回营休养，缺员可通过募兵和招降补充。根据剩余兵员和物资重新安排岗位，准备下一次出战。

营地防守和攻寨各有目标，玩家也可以主动挑战沉眠古窟或野外的土匪窝点。窝点是遗迹附近的小型副本，黑鸦寨是封锁返乡道路的主线据点。返乡重建完成后，玩家仍能经营、应对周期袭击和重复挑战副本。

## 3. 主线体验与关键分支

### 3.1 白桦村清晨与演练

主角在长椅与搭档谈起离开王都后的生活。阿禾为播种缺人，玩家把铁匠铺的两名护村弟兄调去粮田，四人实际到岗后便可找搭档领剑。装备旧短剑，在演练中学会选择队长、暂停、移动、驻守和使用技能。演练刚结束，村民跑来报告古裔正在接近。

### 3.2 西桥断后与东口追兵

搭档率护村队到西桥拖住来敌，主角与阿禾从东口护送乡亲。两名古裔追上来，其中一人持有本应封存在王室武库的秘银剑。追兵战的正常胜败都接入主角被刺伤的结局。老周折返，在避开粮仓的古裔喽啰后，把主角救回灰岩营地。

### 3.3 灰岩营地苏醒与灰岩镇求助

老周交还秘银剑，告诉主角西桥已断、搭档下落仍不明。乡亲暂靠灰岩镇领主接济，主角因此去拜访霍恩爵士，打听异族来历，也为营地争取建设与募兵许可。途中可邀请阿禾，或到灰岩镇铁匠铺与骑枪手阿铸切磋。铁匠巴隆经营装备和重铸，行商老莫提供物资和消息。

### 3.4 沉眠古窟救援

霍恩希望有人调查镇外的沉眠古窟，救出两个失踪镇民。古窟的侵蚀会持续伤害普通人。古窟尚未首通时，主角受击跨过半血线会触发剧情撤回。每个战役进度只触发一次，之后再次挑战按正常战斗结算。独行时，主角会想到去找阿铸。制伏操控镇民的古裔迦兰后，两人解除控制并走向出口，玩家可与被俘的迦兰谈条件。先救人再拜访霍恩也能交差，领主根据发生的事给出对应答复，交付赏金与许可。

### 3.5 灰岩营地整备

玩家回营修复工坊与兵营，找募兵官雷恩招募三种兵。老莫免费透露第一次袭击的时间，玩家可以在日历上查到来袭日期。雷恩在首次成功募兵后提到断壁后的土匪窝点，玩家可去练兵、拿补给，也可先准备首防。

### 3.6 巴图率军袭营

黑鸦寨先锋巴图来抢军械和地盘。玩家可以提前击败全部来敌，也可以坚守三十秒，等敌军开始撤离后结束追击。继续追击有机会击倒巴图。他在这一战倒地便战死，逃脱则可能再次出战。首防败退要承担实际损失，残军次日再来，玩家还可以整备重试。

### 3.7 出征攻寨或留营迎击

首防胜利并完成战后对白后，黑鸦寨主力将在五个游戏日后再次来袭。玩家可以编好出征队，行军一天到山寨，利用当地的窄道、枯树和巨石进攻。也可以留营恢复、继续生产，等大当家带主力上门，在熟悉的阵地迎战。第二波须消灭来敌，主动攻寨获胜则会解除这次来袭。若玩家守胜第二波，斥候陈安会报告寨内残兵已散，玩家可直接返乡，也可先去寨里搜集剩余物资。

### 3.8 返乡调查与重建

队伍回到被掠夺的白桦村，同行伙伴会在进村时说起眼前的变化。玩家可以在麦田边回想开局派工，也可以从村西出门去西桥头。桥头的断剑留有搭档的青绳结，断口和向西延伸的车辙指向下一段调查。玩家可收起断剑，或直接回村。修家时盘问屋里的喽啰，再把受损的粮田和工坊修好。乡亲从村口走回麦田，在这里接过村庄的建设。主角坐回长椅后，播放结尾。

## 4. 代表性设计

### 4.1 同一批人员兼顾生产和出战

士兵既是营地劳力，也能随队出战。主动攻寨时，带走正在种粮、制作军需的士兵，会腾出他们的岗位。灰岩营地的粮田有空岗时，每个空岗额外提供半份工作量，最多计两个空岗。行军当天仍结算营地收支，玩家可以在出发前看净产出，再决定带走多少人。

### 4.2 兵力规模影响伤亡与补员成本

三职业共用总兵力口径，人数进入普通兵倒地后的即死率、每日募兵供应和招募价格计算。兵少时补员更容易、价格较低，继续扩军时要支付更高的单价，倒地减员的风险也会随兵力规模变化。这个反馈给战损后的恢复留出空间，同时限制囤兵带来的优势。

### 4.3 战场上的伤亡决定回营后怎么安排人

倒地的普通兵可能负伤，也可能阵亡。伤员能休养回队，阵亡会永久减少兵力。存活的敌方倒地单位可能成为俘虏，玩家按容量及剧情条件接纳。守下一仗之后，玩家可能手头有战利品却缺能出战的人，也可能靠俘虏补上下一轮阵容。

### 4.4 逐人养成集中在队长

队长有独立装备、技能、特性与训练成长，培养起来的伙伴还可以发挥生产或交易专长。普通兵使用固定的职业模板，玩家按兵种、数量和伤情调配阵容与岗位。装备和技能的长期投入集中在少数有名字的角色身上，扩充部队则主要增加兵种选择和调配空间。

### 4.5 用游戏日安排生产、行军和防守

休息和世界行军都推进生产、恢复、口粮与来袭日期。免费或付费情报揭示已知威胁，日历显示什么时候到来。即使较晚向霍恩交差，首防也会保留准备时间。玩家可以据此安排采购、训练和出征，每次推进一天都有明确收益与代价。

### 4.6 以队长为单位分配指挥注意力

玩家可以暂停，在窄口下驻守命令，给另一个队长下集火命令，再恢复战斗看执行结果。小队策略允许几队自行接敌或守位，玩家也可以空选观战。战斗规模增加时，指挥仍围绕少量队长进行，普通兵在所属小队内行动。

### 4.7 地形和实际占地决定谁适合上场

高地影响视野和弓兵射程，遮挡影响观察和射击。骑兵占一细格，在窄口冲撞时可以顶开非骑兵单位。枯树和巨石属于固定障碍，陷阱和沙袋可改变接敌条件。选兵和部署时需要看地形，兵力优势能发挥多少也取决于落位和接敌路线。

### 4.8 用同一套 D10 判定表现优势与劣势

D10 是十面骰。攻击汇总人物特性和地形等优势、劣势，再决定掷单骰或双骰取高、取低。自然点数也参与必失、必中和暴击判定。玩家可以通过占据有利位置或调整人物配置提高胜算，各种因素共用一套判定方式。

### 4.9 副本把挑战、领奖与扫荡分开

沉眠古窟和土匪窝点各记首通。古窟首胜救人，窝点首胜免费领奖。两个副本重复领奖均需要体力，体力不足时仍能进场试打。满足战力门槛后可扫荡，扫荡仍会发生真实消耗和战损。玩家可以用副本练战、获取补给，或在阵容成熟后缩短重复操作。

### 4.10 古窟让人物身份直接影响战术

侵蚀使普通人越打越危险，主角、阿铸等免疫者可以更久地留在场上。知道这个差异后，玩家可以决定是否更换同行者、缩短战斗，或先撤出去整备。制伏迦兰就能解开镇民的控制，取胜思路也从消灭所有单位转为识别和解决控制来源。

### 4.11 首防的结果改变下一场战役

守到时限便可以结束首防。此时玩家要考虑是否让伤员继续作战，追上巴图并击倒他。巴图的生死决定他会不会出现在下一战。之后，玩家可以选择主动进攻的时间和人数，也可以利用留营的几天恢复并整备。任何一条路线解决黑鸦寨主力，都会改变据点归属并打通返乡路。

### 4.12 任务承接玩家已经完成的行为

先领霍恩的委托再救人，是领命后复命。先救人再去灰岩镇，则由主角直接报告古窟经过，领主认可已经完成的救援。暂缓招募和选择随行者也会改变之后的对白。故事记录玩家的实际经历，这使自由探索的顺序可以进入主线。

### 4.13 让开场教学和返乡收尾发生在同一个村庄

开场让玩家在麦田派工、拿到搭档缠过青绳的旧短剑。返乡时，同一片田和桥头带青绳的断剑，让玩家从熟悉的地点与物件看出劫掠造成的变化。调查之后亲手摆放设施，给「安顿乡亲」这个目标一个看得见的结果。

## 5. 主要界面与操作

| 情境 | 玩家使用的界面 |
| --- | --- |
| 探索与剧情 | 地图上的目标箭头与任务册。肖像和逐页对白呈现故事，末页选项决定答复或进入后续行动 |
| 设施经营 | 岗位、负责人和生产预估同屏。人员名册可以筛选，确认前先看调动后的变化 |
| 装备与交易 | 背包、仓库、商店共用人物卡。物品详情在所选格旁展开，装备和收货对象明确到人 |
| 备战与战斗 | 备战比较已知敌情，再到地图部署。战斗顶栏显示目标与敌我情况，通过头像选队，右下处理策略、暂停和倍速 |
| 战后 | 战果保留伤亡与收益。自动发放的奖励用小窗列明内容和去向，需要处置的俘虏另有操作 |

画面采用俯视像素角色与暖木、暖纸界面。PC 使用键鼠，Android 使用横屏触控。主要操作保持同屏，长名单在各自区域内滚动。
