# 返乡调查与重建 · 场景对白

白桦村外的西桥头连接世界道路与村口。玩家可先取断剑，也可直接进村。家的剧情发生在修门时，麦田旁的村民在三处设施修好后到场。

## 西桥头与村口

| 触发 | 说话人 | 正文 | 后续 |
| --- | --- | --- | --- |
| 靠近西桥头的断剑，主动调查 | 断剑 | 一把断裂的剑躺在地上。剑柄上沾着泥的青绳结，看起来很熟悉。 | 选择收剑或离开。背包满时保留这两个选项。 |
| 第一次进入白桦村 | 旁白 | 门板歪了，粮仓也被搬空。巷子里听不见人声。 | 依随行阵容追加下列各页，读完回到探索。 |
| 阿禾随行 | 阿禾 | 院子翻成这样……人还在，咱们慢慢收拾。 | |
| 阿铸随行 | 阿铸 | 门口的石台都磕掉了一角。走，去西桥头看看。 | |
| 迦兰随行 | 迦兰 | 看这几列脚印。散开的时候，间距还是一样。来的人练过。 | |

## 三处设施

| 位置 | 说话人 | 第一次修理前所见 | 选择修理后 |
| --- | --- | --- | --- |
| 粮田 | 旁白 | 田埂上全是马蹄印。那天清早，阿禾还蹲在这里清点麦种。 | 扣修理费，恢复粮田。 |
| 工坊 | 旁白 | 风箱倒在墙根，钳子和铁料被翻了一地。 | 扣修理费，恢复工坊。 |
| 家 | 旁白 | 自家的门板歪在门框上。 | 开始屋内问话，处置喽啰时扣修理费并恢复房屋。 |

玩家可按任意顺序修理。选择按钮显示当前原料和钱币费用，另有「稍后再来」。

## 修家时的喽啰

| 节点 | 说话人 | 正文 |
| --- | --- | --- |
| 门口动静 | 古裔喽啰 | 外边什么动静？人类？！ |
| 交手 | 旁白 | 你一剑砍服了他们。 |
| 求饶 | 古裔喽啰 | 小的没眼力见，请问有什么吩咐？ |
| 玩家问袭村或问他们在屋里做什么 | 古裔喽啰 | 你是……你不是死了吗？！哎哟，瞧我这乌鸦嘴！ |
| 供述 | 古裔喽啰 | 我们是跟着来的。动手的是首领和精锐大人，哪轮得着我们？我们几个平日就干些端茶递水的活。 |
| 供述 | 古裔喽啰 | 那天闻见这屋里有股香味，就钻进来翻点吃的。等我们出来，首领早带人走了，像是有急事，连叫都没叫我们一声。 |
| 重开处置选项 | 古裔喽啰 | 大人，还有什么吩咐？ |
| 追问迦兰，可重复 | 古裔喽啰 | 迦兰？当然认识。跟我们一起出发的，半路上就不见了。 |
| 追问时迦兰随行 | 古裔喽啰 | 哎哟，这不就是迦兰队长吗？别来无恙啊！ |
| 放走 | 古裔喽啰 | 大人慈悲！小的这就告辞，再不踏进村子半步。 |
| 放走时迦兰随行 | 古裔喽啰 | 不过，屋外那位可是跟我们一起出的门，半道上就没影了。如今跟了您，您可得留个心眼。 |
| 上述任一当面指认后 | 迦兰 | 少蛊惑人心，我已经是这位大人的忠仆了。 |
| 处死 | 古裔喽啰 | 呃啊！ |

喽啰只在对白中出现。追问后回到放走、追问、处死三个选项。放走和处死均结束本次遭遇。
