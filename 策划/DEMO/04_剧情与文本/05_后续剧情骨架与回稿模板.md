# 后续剧情骨架与回稿模板

按场景发稿。每批附上已填好的骨架、相关人物声音卡和术语、已有正文。写作口径与播放规格见 [对白播放规格](06_对白播放规格与接入.md)，可改写范围见 [可改写范围](06_对白播放规格与接入.md)。

## 1. 后续剧情骨架

每章复制一次章节表。每个可独立触发的节点复制一次场景表。已有场景单独改稿时，从场景表开始即可。后续剧情先填写本页章节与场景骨架，确认纳入Demo后分别登记到本卷场景对白与[物品文本](03_物品技能与任务文本.md)。

### 1.1 章节表

| 字段 | 填写 |
| --- | --- |
| 章节与适用范围 | 〈章节名，Demo 或完整游戏〉 |
| 承接与起点 | 〈上一章结局，玩家此刻所在地点、已知线索和拥有的凭证〉 |
| 本章目标 | 〈玩家要做什么，主要冲突是什么〉 |
| 线索与揭示顺序 | 〈何时从谁或什么证物得知什么，本章结束时知道多少〉 |
| 场景顺序 | 〈起始场景 → 可选分支 → 汇合或各自结局，用场景名称〉 |
| 结束与下一章入口 | 〈任务或世界状态，解锁内容，玩家接下来去哪里〉 |
| 待确认 | 〈尚未确定的人物、事实、机制或表现；无则填无〉 |

### 1.2 场景表

| 字段 | 填写 |
| --- | --- |
| 场景与节点 | 〈地点 · 玩家正在经历的事件〉 |
| 本段要传达的信息 | 〈目的、已确认事实、玩家此前知道什么〉 |
| 触发与排除 | 〈玩家动作或事件，前置阶段，首次或重复，哪些状态跳过〉 |
| 在场人物 | 〈角色身份、玩家看到的称呼、口吻，缺席时走哪段〉 |
| 播放与顺序 | 〈逐段注明 NPC 连续对白、旁白、玩家整句答复，或短选项及点选后播放的主角原话。标出页数、可否中途关闭、战前／战中／战后时点〉 |
| 选项或末页去向 | 〈选项见下表，或填无选项及末页继续后的动作〉 |
| 进度记录与回退 | 〈在哪一步记录任务、线索或一次性标记，重复、退出、失败或缺席怎么处理〉 |
| 本批写作要求 | 〈逐页要点、语气、允许变量和字数，按条目标记待写／待改写／只读〉 |
| 接入状态 | 〈已有入口／需新增触发、分支或显示位置。运行位置由本地核对〉 |

| 页序 | 条目 ID | 说话人 | 本页要传达的信息 | 当前正文 | 回稿范围 | 变量与字数 |
| --- | --- | --- | --- | --- | --- | --- |
| 〈1〉 | 〈已有 ID 或策划 ID〉 | 〈角色〉 | 〈本页要点〉 | 〈现有原文或待写〉 | 〈待写／待改写／只读〉 | 〈变量及含义，展开后上限〉 |

| 末页选项 ID | 当前答复 | 回稿范围 | 显示与可用条件 | 点击结果和下一节点 |
| --- | --- | --- | --- | --- |
| 〈ID〉 | 〈原文或待写〉 | 〈待写／待改写／只读〉 | 〈何时显示，何时可点〉 | 〈原动作及其结果〉 |

无选项时，填写「无」和末页去向即可。中途要由玩家决定时，把决定前的对白和决定后的各条路线分别填为节点。物品描述按下表给出写作依据。某件装备还没有风味描述的显示位置时，在接入状态注明「显示位置待定」。

| 条目 ID | 物品 ID 与正式名称 | 显示位置 | 已确认来源或用途 | 当前描述 | 回稿范围 | 变量与字数 | 接入状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 〈回稿对照 ID〉 | 〈物品身份〉 | 〈背包详情等〉 | 〈已确认事实〉 | 〈原文或待写〉 | 〈待写／待改写／只读〉 | 〈变量及含义，展开后上限〉 | 〈已有位置／待接入〉 |

## 2. 网页 AI 回稿模板

发送时复制本节，把当批的场景表、人物声音卡和术语附在后面。

> 只填写标为「待写」或「待改写」的剧情对白、人物闲聊、带伤应答、独白、旁白、剧情答复和物品描述。菜单、固定按钮、系统提示、正式专名、物品属性与数值按原稿。
>
> 一行对应一页或一项描述，保留条目 ID、页序、说话人和给定变量。普通对白每页 15～30 字，含标点。按条目执行例外上限，并计入变量展开后的长度。正文填写玩家看到的纯文本，镜头、动作或音效建议另列备注。
>
> 末页才出现可操作的答复。只改标为可改写的措辞，沿用给出的选项数量、出现条件与结果。需要额外页面、人物、动作、触发或分支时，在待确认表说明。
>
> 物品描述只写已确认的风味与用途。按显示位置的限制写，保留正式名称和机制。正文缺少必要事实时，用待确认表指出缺口。

**回稿正文**

| 条目 ID | 类型 | 页序与说话人／物品及显示位置 | 回稿正文 | 变量与字数 |
| --- | --- | --- | --- | --- |
| 〈照抄 ID〉 | 〈对白／独白／旁白／剧情答复／物品描述〉 | 〈按骨架填写〉 | 〈玩家看到的文字〉 | 〈原变量、字数〉 |

**待确认与演出备注**

| 关联条目 | 类别 | 需要确认的事实、触发或演出 |
| --- | --- | --- |
| 〈ID〉 | 〈事实／触发／表现〉 | 〈问题或建议。无则填无〉 |

网页 AI 回稿后，由策划确认正文。本地 agent 核对运行入口。已有文本键按键更新。只有策划 ID 的条目先定位脚本、场景或物品数据。记录「文案定稿」和「游戏已接入」两个状态。

## 3. 已有场景示例：雷恩首次购兵线索

| 字段 | 内容 |
| --- | --- |
| 场景 | 灰岩镇募兵处 |
| 触发 | 本局首次成功购买普通士兵后退出募兵界面，线索标记未完成 |
| 在场 | 主角与雷恩；不要求阿禾或阿铸在场 |
| 播放 | 连续三页，结束去向沿用离开募兵界面时选择的关闭或返回对话。购兵时在原页刷新报价 |

| 回稿边界 | 三页主观台词可改写，招募结果、窝点位置和奖励方式只读 |
