# 世界术语与人物

## 故事范围

主角和搭档离开王都后在白桦村生活一年。异族精锐闯入村庄，两人分头掩护乡亲；搭档留在西桥失踪，主角在东口被王室秘银剑刺穿，后由老周救至灰岩营地。主角为乡亲争取立足之地，查古窟、组织营地并打通返乡道路，最后找到搭档断剑与向西车辙。

白桦村遭掠夺而未遭火焚。追兵明确为古裔，不是人类王都军队。王室剑为何在异族手中、搭档去向与西山势力在 Demo 内仍未知；罗盘不具有定位所有异能者的功能。

## 术语

| 词 | 当前含义 |
| --- | --- |
| 异族／古裔 | 剧情敌人与迦兰所属人群，角色身份与三种战斗职业分开 |
| 异能者 | 主角与阿铸等侵蚀免疫身份；未正式切换为网页回稿建议的其他新名 |
| 沉眠古窟 | 正式副本名，口语可称古窟；沿当前地图与任务名称 |
| 魂丝／侵蚀 | 迦兰控制镇民和副本内普通人受损的既有事实；没有新增追踪法术 |
| 王室秘银长剑 | 东口异族所持、后来交还主角的线索物品 |
| 旧制短剑 | 序章搭档交给主角的剑，青绳为独特叙事细节 |
| 搭档的断剑 | 返乡桥头证物，青绳沾泥；不是主角序章剑被自动替换 |
| 灰岩营地 | 白桦村乡亲在灰岩镇西边的落脚地。场景、地图和任务使用「灰岩营地」。对白通常说「营地」，交代位置可用「灰岩镇外的营地」「灰岩镇西边的营地」，强调难民身份时可用「难民营地」 |
| 灰岩镇／黑鸦寨 | 领主驻地／辖区外独立匪寨 |
| 土匪窝点 | 墙后普通副本，和主线黑鸦寨分开 |

称呼和地名由运行专名表统一，文本键保存玩家正文。全作真相、长期西山剧情和未定命名不混入当前 Demo 台词。
