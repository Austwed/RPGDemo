# 沉眠古窟与土匪窝点

## 入口和地图

古窟在野外遗迹入口，碰撞体阻止人物穿过建筑，周围断壁封住原缺口。土匪窝点在右侧断壁东面，使用普通地形的迷雾规则：浓雾隐藏，薄雾显示，绕墙探索即可发现。不是单独的剧情发现开关。窝点地图实例复用地下回廊地形与部署区。

首防预告和来袭当天均可从灰岩镇东口往返古窟外侧野地。领地内转场、进入古窟、战斗和战果处理均在同一游戏日完成。路线条件在发起转场及存档前检查。

## 对比

| 项目 | 沉眠古窟 | 土匪窝点 |
| --- | --- | --- |
| 主线作用 | 首通救援、证据、迦兰与霍恩交差 | 独立普通副本 |
| 敌阵 | 初次为迦兰与两名受控镇民。首通后为一名异族队长与两名普通黑袍法师。异族队长使用迦兰外观，按补充批次显示「异族队长1」「异族队长2」等名称 | 入口交互时生成固定人数、三职业等概率随机的普通土匪，无队长 |
| 场内危险 | 普通人最大生命每秒 3% 侵蚀 | 无侵蚀 |
| 警告 | 按实际落位，含非免疫者时在部署底栏显示生命损失 | 无古窟侵蚀警告 |
| 阵容保留 | 本次准备到开战冻结 | 同次交互预览、部署、返回与开战共用一份敌阵快照 |
| 首胜与重打 | 首胜接救人对白；再战须歼灭全部敌人，再从出口离场并处理战果与俘虏 | 常规战果、俘虏和同类体力奖励 |
| 扫荡 | 首通后开放；严格战力门槛 | 首通后同样开放 |

## 古窟首次开战

可以先接委托再来，也可以直接救人。进入既有战场后默认可部署。底栏按实际落位更新侵蚀提示。从带有提示的部署返回备战可解锁「谨慎为上」。主角、阿铸、阿禾首次到达入口时分别触发对白。阿禾可留在洞口，出洞后再邀随行。迦兰初次隔空喊话，自报姓名，肖像显示问号。首通前重来，他用本人肖像认出玩家。两次都可以继续或先退出准备。

首通前，主角独行或带队受击首次跨过半血线时撤回入口。剧情撤退在同一战役只结算一次。带伤重进或恢复后再挑战时按实际生命交战。战损和军需按本场结算。独行回到入口会播主角独白「对方人多势众，优势不在我，或许镇上那位年轻铁匠可以帮忙。」，没有当前目标页或系统说明。靠成长、装备或操作独胜也属于合法首通。

## 首胜及俘虏

制伏迦兰后停止交战与侵蚀，两名镇民在地下回廊醒来，当场开口道谢。对白结束后，他们隐藏战斗标记，成为不可攻击的普通镇民并自行走向出口。玩家仍可操控自己队伍，任一在场可行动队长抵达我方出口即可带全队返回入口。镇民先到时战果保持待结算。原本站在出口格里的队长会原地等候，点脚下格即可离开。骑兵同样按脚下的一细格判定。若仅剩普通兵，点出口格让幸存士兵带队离开。首胜只有救援剧情，战损照常保存，副本物品、资源与战果窗口均不出现。

出洞后先接镇民告别。迦兰站在遗迹入口，和他交谈可接纳、让他等候或处死。营帐已满、关闭对白或先去镇上交差，都可再回来找他。洞外可以反复问起地脉和白桦村。质问操控百姓再听其起誓可接纳；在初问或誓言末页选择「不论如何，操控百姓当斩」，他惊呼后倒地，当场无法交互，离开入口再回来时遗体消失。返乡插页只认首通接纳的具名迦兰。

## 副本奖励和扫荡

再战的两名法师会受热脉伤害，异族队长倒地后仍会自主交战。只有异族队长和两名法师均失去作战能力才锁定胜利。异族队长和法师走普通伤亡、俘虏和招降流程，存活并满足捕获条件的可在战果中招募。法师入士兵名册并取得实名编号，异族队长按营帐容量接纳。雷恩和遗迹旁土匪窝点只提供剑、弓、骑三种兵源。

窝点攻打和扫荡、古窟再战和扫荡在确认时各消耗 20 点体力。古窟首通救援免体力。体力上限 120，每日恢复 40。窝点首胜含首通补充奖励，两副本分别记录首通与每场领奖进度。[战果与副本](../01_系统规则/09_战果奖励与副本.md)

扫荡复用当前备战编队与单档军需，己方战力必须严格大于参考敌力 1.5 倍。确认前不列预计战损，确认后按模型结算。取消不耗体力、军需或物品。古窟有侵蚀，窝点没有。

## 核对点

首通敌配置、重复战参考与窝点人数取运行快照；文本不能写死「普通人几息必死」或强制带阿铸。敌阵快照、战斗时钟、战果提交 ID 与奖励领取 ID 分开保存，重复确认不重发奖励。
