# 白桦村序章

## 进入与场景

新档从白桦村长椅开始。先选择主角外观与性别，再输入姓名并确认；姓名通过规则后建立新版存档前缀。搭档使用对应人物资源，称呼为「搭档」。双方曾离开王都，在村里生活一年。序章使用正式村庄地图、人员调配和战场界面。

## 教学节点

| 顺序 | 玩家操作与条件 | 提交与指引 |
| --- | --- | --- |
| 长椅 | 与搭档对话；可多问王都旧事两页 | 两条路径汇回寻找阿禾，不重复发物品 |
| 派工 | 阿禾交代田里二人、铁匠铺二人 | 在粮田名册点选两名铁匠铺剑士调入，箭头先指可调入的士兵，再指确认方案 |
| 确认到岗 | 实际确认粮田四人 | 自动完成派工，阿禾与搭档接话，箭头转向搭档 |
| 领剑 | 主角开局武器槽为空。与搭档交谈并领取旧制短剑 | 进入个人背包，青绳描述跟随该实例，演练和撤离后继续持有 |
| 装备 | 把短剑装备到武器槽 | 预览、关闭背包不能代替装备成功 |
| 演练 | 选人、暂停、实际移动、练木桩，再命中搭档 | 箭头指向当前操作目标，玩家主动选人后推进。木桩环节可通过进攻策略自动命中三次，或打坏木桩。 |
| 报信 | 完成演练接村民来袭报告 | 报信人在村道上方停下，附近的搭档、阿禾、春婶、老周和村民沿已算出的路线走到他身边并朝向他。到场保存当前进度，局部刷新人员与对白。搭档随后率四名护村弟兄守西桥，玩家护送乡亲向东 |
| 撤离 | 抵达东侧触发范围并满足撤离条件 | 进入两名古裔追兵战 |

演练中提前选「进攻」，主角会等搭档示范结束，再自行走到木桩旁连续出手。重复点「进攻」会保留正在执行的木桩攻击。换回「手动」可自行下令。

设施草案可取消；只有实际调动到四人推进。教学内部以 Intro 步骤和行为记录判断，不用大块进度弹窗。普通移动、取物、装备使用正式系统。

粮田与铁匠铺的序章预估使用四名护村剑士的口粮，共4粮。初始两人耕作净增4粮，确认四人耕作后净增12粮。主角与搭档日口粮为0。

春婶任粮田管理员，老周任铁匠铺管理员，两人占用固定的管理员岗位。序章任职不改变产量和工人名额。

## 追兵与汇合

两名追兵是古裔，使用迦兰系战斗贴图，保留各自剧情身份。主角在开战对白认出王室秘银剑。正常胜败统一接刺伤：一名追兵用王室剑贯穿主角，双方力竭倒下，主角失去意识，低阶异族喽啰去粮仓翻找食物。对白随后进入灰岩营地，不要求失败重打。

主动放弃追兵战回撤离节点，重新建立撤离者；回主菜单或退出游戏直接丢弃会话，不播放重伤结局、不结算或写新档。白桦村遭闯入与掠夺，未被烧毁。

## 离开与复用

老周骑马绕过粮仓喽啰，从东侧救回主角。序章人物、派工及撤离状态由存档保存；返乡复用村庄地点但使用返乡对象、对白与建设事务。逐页正文见[序章对白](../04_剧情与文本/对白/01_白桦村序章.md)。
