# PC 与安卓输入及适配

## 操作对应

| 情境 | 键鼠 | 安卓横屏触控 |
| --- | --- | --- |
| 探索移动 | WASD／方向键，单轴输入立即朝向 | 当前安卓使用左侧触屏摇杆，右侧就近交互按钮；PC 隐藏摇杆 |
| 交互 | 面向近处目标按 E 或可用交互按钮 | 点交互目标与就近操作 |
| 对白推进 | 点正文、E、空格先显全句再下一页 | 点正文同样两段推进 |
| 选择队长 | 点头像、滑选 | 点头像、滑选 |
| 移动／查看 | 地图点格，按当前模式下令 | 地图点格 |
| 驻守 | 双击合法目标 | 长按合法目标 |
| 部署 | 从部署格拖划连续放兵；单位上起手换位；区外空地左拖平移 | 点格与连续布兵，单位拖放及现有相机手势 |
| 开战 | 底部开战或空格 | 底部开战 |
| 暂停与策略 | 右下五键 | 同一五键命中区 |

按键与触屏只改变输入入口，资格、路径、落点、物品和提交规则共用。菜单、对话和物品小窗上的触摸不穿透地图。

## 安全区与缩放

以实际安全区域计算 16∶9 游戏框，1280×720 逻辑单位整体缩放。横幅锚到框的上下边，菜单锚右上。长名单、台词和商品使用局部空间，不靠自动缩字保住排版。角色背包外框按人数档变化，不随空白任意铺满屏幕。

需要覆盖 1280×720、1920×1080、1024×640，以及安卓小屏 854×480、960×432。后二者要同时检查正文阅读、长按／拖动冲突、五键误触与安全区边界。画面截图和输入执行分别记录，离屏图不能代替手势结果。

## 平台配置

当前项目 Android 最低 API 26，目标 API 36，允许左右横屏、不允许竖屏。构建版本与架构以发布说明为准。APK 的体积检查区分压缩安装包、展开文件与首次运行数据；不把编辑器源码、测试档和策划原文放入发行包。
