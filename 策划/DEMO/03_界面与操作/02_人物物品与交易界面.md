# 人物物品与交易界面

## 人物与背包

物品小窗内按所选数量直接销毁。堆叠物品的销毁按钮同时显示本次销毁数量，穿戴中和受保护的物品隐藏销毁操作。

独立背包使用固定大小人物卡，一人居中，两人或三人并排。外框一／二／三人初值为 372／706／1040，统一高 576，场景可调。全身像居中，装备槽分两侧，下面是 5×4 共 20 格；整理、分类、装备、转移、拖放和锁定槽沿用正式物品系统。

装备槽、背包和仓库物品格共用 Unity 预制体，运行时绑定物品、数量、品质与槽位名称。背包底排与人物卡下缘留内边距。全身像与两列装备槽对齐。骑乘像按骑手头顶至马蹄的高度裁切，超出头顶的武器部分不计入取景。物品图标居中，堆叠数量保留角标，槽名显示在装备格底部。点击或触屏点选在物品附近弹紧凑小窗，显示图标、全名、属性及当前可用操作。未穿戴的装备可在小窗穿戴，已穿戴的装备可从装备槽拖回背包。拖动预览使用同一图标。小窗靠屏边换侧或约束到可见区域，关闭不会改变物品。取消独立的大物品详情页。固定字号不因物品名长而缩小。独立背包和仓库在原界面点选物品、开关贴格小窗和调整数量。

物品格用像素资源框区分品质。装备和武器按实例当前品质显示。持有和穿戴改变数值，角色使用固定外形。

| 品质或物品 | 底色 |
| --- | --- |
| 破损 | 红色 |
| 较差 | 棕色 |
| 一般装备与武器、普通物品、主角指环 | 白色 |
| 良好、高阶兵书、烈酒 | 绿色 |
| 极佳 | 蓝色 |
| 传奇 | 金色 |
| 任务道具 | 橙色 |

## 仓库

仓库和交易页右侧的角色切换栏按三个等宽位置从左排列。空位留白，仓库人数超过三人时可横向滚动。左侧区域铺满共享仓库格，右侧放同一人物卡与可切换随行角色。左侧不设固定大详情栏。格子显示模板不等于实际仓库容量；容量与实例归属由物品数据决定。左右拖放、堆叠、锁定、任务物品限制和失败回滚共用背包事务。

## 交易

左侧 NPC 肖像与发言，中间货架、所选商品、数量与确认，右侧同一可切换人物卡。购买个人装备收给当前角色，确认时重新检查角色可访问、空位、金币、库存与报价；满包显示「背包已满」浮动提示，失败不扣钱不动货。点个人物品可出售，公共物资买卖在商品详情完成。

货架行显示名称和单价，余量在商品详情显示。商品售罄后货架行变暗，仍可选中查看详情。装备商品详情显示物品属性、单价和可售状态，武器显示「攻击距离」，省去换装前后对比。粮草、原料、军需、锻造石、酒和兵书共用数量、最多、总价与确认控件。公共资源可切换买入、卖出，入包商品沿用背包图标。切换商品、调整数量和确认交易在原商店窗口内完成。

老莫的对白提供「买卖东西」和「小道消息」。常用物资、锻造石、酒和已解锁的兵书按同一货架浏览，玩家可以向老莫出售装备。可补领的首防免费情报和付费消息同在「小道消息」。付费情报货架用「五日军情」和「十日军情」作名称，日期范围、兵力等内容在详情区显示。巴隆的对白提供商品与重铸，装备由巴隆出售。军官右侧使用只读名册，逐人招募并立即重报价。募兵页的 NPC、货架、详情和名册四区上下对齐。未解锁功能不预先画灰按钮。

## 重铸和奖励

铁匠重铸使用当前可访问背包及已穿戴装备，列出材料、投入数量、概率和结果。确认前检查实例未变化；结果按一次事务更新。营地工坊不提供该入口。

自动奖励使用小窗列物品、数量与去向，先发放再展示，关闭不确认领取。装不下的战场掉落保留待领。需要选择、付体力或处置俘虏的界面仍保留对应操作，不混同自动奖励。
