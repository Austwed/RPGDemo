## 计算样例

单档配给需求等于实际落位普通兵数。三名队长带 4 剑士、3 弓兵、3 骑兵全部落位时需求为10；只落位 2 剑士、1 弓兵、1 骑兵时需求为4。队长不增加需求。

军需库存12，另有配额3，本队可用9。若实际出战6，提交后库存总量仍12，配额总量9，可用3。正式结束本队后库存6，剩余其他配额3，可用3。

古窟再战前体力 60，确认入场后为 40，结算与领奖仍为 40，再过一天按每日恢复 40 成为 80。

## 设计与实现差异

令同兵种同生命的两人只上一人，战后核对固定编号。已参战者当天禁工但可再战，未落位者可工作。低血者治疗越过 30% 后仍显示当日参战；核对本日预估与过日实产，次日恢复资格。战后俘虏处置及死亡敏感度另按对应版本验收。

## 即时战斗规则验收

配置使用 Unity `556b4bf` 的运行快照。隔离场景按用例使用固定种子和 1000／10000 生命的测试单位，采集目标 ID、施击位置、路径与攻击包。用相同站位增减一个条件，再比较组合结果。正式首防使用现有阶段档。

| 用例 | 前置与操作 | 预期及实测 |
| --- | --- | --- |
| 战规01 · 权重 | 让弓兵面对普通、嘲讽和小透明三个可射目标，清空已有索敌后推进。再让普通目标与嘲讽目标的距离除以权重相同 | 首选嘲讽 ID 2。同分时选更小的普通目标 ID 1；小透明权重 0.5，近处的小透明也可排在更远的普通目标之后 |
| 战规02 · 改选 | 将嘲讽目标分别移出射程、放在墙后、令其落入视野外或倒地。恢复可见，再清空原目标 | 四种情况均选普通 ID 1。恢复可见时继续打当前可射的普通目标；清空后重选嘲讽 ID 2 |
| 战规03 · 集火与断路 | 以水域隔断步行路径但保留射线，重新索敌，再显式集火普通目标 | 隔水自动选中嘲讽 ID 2，显式集火改为普通 ID 1。隔墙时从属弓兵实际攻击无遮挡的 ID 2，射线恢复后回到 ID 1。两种情况下队长的原集火指令均保留 |

## 职业数值复验

使用正式即时模拟的平地自动对局，普通难度，双方互换出生侧。另取四个独立种子，普通兵覆盖每方 8 或 16 人及无军需、一阶、二阶同档军需。剑士对骑兵胜 48/48，骑兵对弓兵胜 47/48。裸装一级普通、异能队长分别对位，两类各为剑胜骑 8/8、骑胜弓 8/8。阿铸初装切磋由原档 14/24 胜提高至 24/24。这里的分数用于对位回归，适用条件为该组规则、地形与种子。

普通兵在无军需、无暴击条件下，剑士和弓兵分别对裸装一级异能剑士队长造成 4、6 点伤害。高等级重甲继续显著压低普通物理攻击。例如九级异能剑士配一般品质重甲，防御 16.28，一级军需剑兵命中伤害约 1.72，弓兵约 3.72，法师约 6.95。

独立工程用正式导表工具核对 33 个配置字段，重建四份随包阶段档。试玩表初始配置与总表、运行快照比较均为零差异。

## 基础军需、二级增幅与骑兵远端攻击

前节为改动前的同档对照。现行新档一级军需保留按人消耗，二级攻、血、防均为 +30%。平地普通难度、固定种子、互换出生侧，一级和二级剑骑单挑中剑士分别胜 30/32、32/32。16 对 16 的剑骑和骑弓对位在每档各复验 8 局，均由预期优势方获胜。固定骑兵站位，在第一细格内用单骰，超出第一细格但仍可攻击时掷两骰取低。回归核对正式备战、生命上限、存读档与归队伤情。
