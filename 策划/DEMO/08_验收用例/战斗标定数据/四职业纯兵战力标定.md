# 四职业纯兵战力标定

按当前规则快照运行 Unity 正式实时模拟。训练 360 局，独立种子复验 288 局。普通难度、一级满血普通兵、没有队长，双方军需档相同。每组对调出生侧。受限地图用居中的对称障碍分出两条通道。90 秒未分胜负记为超时，拟合时按半胜处理。

| 职业 | 折算值 | 约 1000 战力人数 | 实际战力 |

剑士设为 100，以训练组的对局胜负和人数比拟合剩余职业，固定小幅正则项约束极端偏重。独立样本的胜负概率均方误差为 0.269，各场一律按 50% 估计的基线为 0.250。

为检查人数取整的影响，另用新种子复验 48 局。7 名骑兵战力 1059.73，12 名弓兵战力 1075.80。骑兵胜 24，弓兵胜 24，平局 0，超时 0。

按最接近 1000 的整数人数，骑兵胜 43 局、弓兵胜 5 局，平局 0 局，超时 0 局。两边实际战力见人数表。

将两队实际战力拉近，并让骑兵总分略低后，骑兵没有赢得更多。当前单兵值只能作候选，尚不足以稳健表达等战力下的弓骑克制。

下一轮可将总体战力和交战克制分别验证。先用单兵分衡量规模，再把各职业对阵的实测得分率与模型预测的差作为候选修正，用独立种子和混编队伍检查。当前配表、备战战力与扫荡沿用既有值。
