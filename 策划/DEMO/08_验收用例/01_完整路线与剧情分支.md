# 完整路线与剧情分支

## 主路线

| 用例 | 前置与操作 | 可见预期及记录 |
| --- | --- | --- |
| 路线01 | 无兼容档，选主角、输入合法姓名 | 长椅开始，主角名正确；姓名确认后产生首自动档 |
| 路线02 | 长椅先问旧事，再找阿禾 | 点选话题后听搭档讲那次值夜，随后选一起去找阿禾，目标仍指向粮田 |
| 路线03 | 派工草案改四人但取消，再实际确认四人 | 四名剑士的口粮均计入，合计4。粮田2人时净增4，4人时净增12。取消不完成，确认后自动接话并指向搭档 |
| 路线04 | 领剑，打开背包但不装备，再装备 | 仅实际装备通过；青绳描述只在相应剑实例 |
| 路线05 | 选人、暂停、实际移动。搭档示范期间点进攻，等主角出手后再点一次进攻。另走手动打坏木桩路线，最后命中搭档 | 指引逐步更新。主角在示范期间保持原位，示范结束后接近木桩，停步连续命中三次。重复点击保留当前前摇。两条路线均接搭档交手和报信。 |
| 路线06 | 报信与告别，带乡亲向东 | 搭档守西桥，东口出现两名古裔与王室剑对白 |
| 路线07 | 正常结束追兵战 | 王室剑刺伤、喽啰对白、灰岩营地苏醒连续进入。新营地第1日仅有主角，口粮为0，粮食240 |
| 路线08 | 苏醒后邀请阿禾、调工、去灰岩镇 | 招募与粮田任职分开，老周交代救援与去领主动机 |
| 路线09 | 初见霍恩，分别逐页读和跳过 NPC 台词；再与阿铸切磋、邀请入营并领取赠礼 | 两条读法都会停在主角答复和接受调查的选项处，选中接受后只接取一次。切磋获胜与落败显示各自的夸奖，战前状态恢复，两种结果都可邀请。主动放弃可重试。入营后赠礼只发一次 |
| 路线10 | 在古窟听见喊话，先退出备战，再回来选「继续推进」 | 初遇显示问号姓名与肖像。退出后在入口，继续时听完第二句才开战 |
| 路线11 | 配置可用的同伴与装备并实际战胜控制者 | 洞内先听镇民开口，再看两名镇民无血条走向出口。玩家可操作队伍，任一可控队员踏入出口后才回洞外。首胜无奖励窗；再与镇民交谈、回城交差 |
| 路线12 | 霍恩交差、逐人购三职业兵、领老莫情报 | 许可与奖励一次。成功购兵后报价更新；退出募兵页时雷恩道出窝点线索。来袭日期进入日历 |
| 路线13 | 修工坊兵营、安排生产、休息至入侵 | 费用一次，真实军需产出，陈安到期报告，不能休息跳过 |
| 路线14 | 首防布兵、单档军需、守满时限并结束追击 | 敌撤离，巴图死逃按真实战场状态，开启第二波倒计时 |
| 路线15 | 编出征队，世界道路一天到寨，主动攻营获胜 | 候选来自抵达队，接管、取消第二波、开放返乡 |
| 路线16 | 再行军到白桦村，读开场、田边、村民、断剑 | 仅实际同行者插话；断剑可略过，原址修理可直接进行 |
| 路线17 | 在原址分别修家、粮田与工坊，和到达麦田的村民交谈 | 每处按现行价格扣费一次。可暂不建兵营并完成主线。独白后淡入「试玩篇完」，可继续探索或回主菜单。 |

## 存档插入点

在姓名后、实际切图后、最终确认开战前、战后回探索后分别读取自动档核对地点和落点。在部署取消、对白中、战斗进行中直接回主菜单再读档，确认没有把未保存会话写回。返乡开场前自动档允许重新播放尚未完成标记的开场。

临时比武和演练不出现旧战果说明，正式战斗仍有真实伤亡与奖励。所有路线使用正式入口与正常玩法触发，不在游玩验收中改血量模拟通过。
